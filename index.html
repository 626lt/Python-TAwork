    2026 秋冬 Python 课程资料

    本网站是浙江大学 2026–2027 学年秋冬学期《Python 程序设计》课程的学习资料，主要为沈睿老师的教学班整理. 网站面向没有编程基础的同学，讲解基于课上内容，并尽量联系 PTA 上的作业和考试. 阅读时，建议打开 Thonny，把例子亲手输入一遍.

    网站内容

    • 基础知识：在课程范围内系统地讲解 Python 的基础内容，适合跟着课程进度学习，也适合考前复习. 其中的 PTA 测试方法是每位同学都必须掌握的，建议在做第一次作业之前读完.
    • 常见问题：从同学们的真实提问中整理而来，适合遇到具体问题时查阅. 实验考试之前，请务必读一读关于实验考试的提示.
    • 历史资料：往年的实验文档和补充资料，仅供参考，其中的要求不代表本学期的安排.

    常用资源

    • Thonny 官方网站：Thonny 是一个简单的 Python 集成开发环境，适合初学者使用. 它自带 Python，安装 Thonny 之后不需要再单独安装 Python.
    • Python 官方网站与 VS Code：如果不使用 Thonny，我们推荐从 Python 官网下载安装 Python，再安装 VS Code 和其中的 Python、Pylance 两个插件（VS Code 中称为“扩展”），用它们来编写程序、学习 Python. 安装 Python 插件时，Pylance 一般会被一并自动安装.
    • Python 官方教程：官方的中文教程，足够有趣且足够丰富.

    提问

    可以通过钉钉私信向助教提问，也可以通过其他方式提问，我们会尽可能在第一时间回答. 提问之前，建议先读一读提问的智慧（中译版），这是 LUG @ USTC 翻译的经典文章，能帮你把问题问清楚，更快得到有用的回答.
